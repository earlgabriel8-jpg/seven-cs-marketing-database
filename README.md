# seven-cs-marketing-database
Seven CS Marketing Database Project

Project Description

The Seven CS Marketing Database Project is a relational database designed to organize and manage business-related information. It includes records for users, products, customers, suppliers, sales, payments, inventory, and deliveries.

Technologies Used

- MySQL
- MariaDB
- SQL
- phpMyAdmin

Database Features

- User and role management
- Product and category management
- Customer and supplier records
- Sales and payment management
- Inventory and stock tracking
- Purchase order management
- Delivery and delivery tracking
- Audit logs

Project Files

- "seven_cs_marketing (1).sql" – SQL database export containing the database structure and sample records.
- "README.md" – Project documentation.
- "screenshots" posted – Entity Relationship Diagram.

Project Purpose

This project demonstrates the use of relational database concepts, SQL, database relationships, primary keys, foreign keys, and database management.

Academic Purpose

This database project was prepared as part of an academic requirement to demonstrate practical knowledge of database design and SQL.
